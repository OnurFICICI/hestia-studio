# Getting help

Hestia Studio is a community-maintained theme. Help is offered as time allows; there is no guaranteed response time or commercial support agreement.

| Need | Where to go |
| --- | --- |
| Install, update, restore, or remove Studio | [Installation guide](docs/INSTALLATION.md) |
| Theme selected in server settings but not visible | Select `studio` in your own user profile's **Theme** field too, save, then hard-refresh. Server defaults and saved user preferences are separate. |
| Supported HestiaCP versions and testing limits | [Compatibility](docs/COMPATIBILITY.md) |
| Usage question, idea, or community showcase | Open this repository's **Discussions** tab. Use **Q&A** for questions and mark a useful answer when resolved. |
| Reproducible theme bug or focused feature proposal | Open the **Issues** tab, search existing reports, then choose the relevant template. |
| Contribution or translation | [Contributing](CONTRIBUTING.md) and [translating](docs/TRANSLATING.md) |
| Suspected security vulnerability | Follow [SECURITY.md](SECURITY.md) and report privately. |

For a useful report, include Studio and HestiaCP versions, browser, language, account role, appearance, accent, reproduction steps, and expected versus actual behavior. Reproduce with fictional accounts and reserved example domains. Remove real domains, IP addresses, email addresses, credentials, cookies, and customer data from screenshots and logs before posting.

If a problem also occurs with HestiaCP's default theme, investigate it through the official [HestiaCP documentation](https://hestiacp.com/docs/) or community support. Do not switch themes or reproduce destructive operations on a live server solely for a report; use a disposable test installation.
